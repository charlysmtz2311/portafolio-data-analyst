##  Proyectos Destacados en este Portafolio

### 1. Dashboard de Ventas y Rendimiento de Canal (Sell-Out)
* **El Reto:** Falta de visibilidad en tiempo real sobre la rotación de producto y auditoría de inventarios en puntos de venta externos.
* **La Solución:** Desarrollo de un dashboard interactivo en **Looker Studio** conectado a bases de datos estructuradas para el seguimiento de métricas comerciales.
* **Impacto:** Resurtido optimizado y control preciso de mermas e inventario.

### 2. Aplicación Móvil y Base de Datos Operativa (Gestión de Comercio)
* **El Reto:** Descentralización en el registro de padrones y seguimiento operativo en campo.
* **La Solución:** Creación de una aplicación a la medida utilizando **AppSheet y Google Sheets**, integrando geolocalización y control de registros centralizado.
* **Impacto:** Eliminación de errores manuales y trazabilidad en tiempo real para la toma de decisiones.
