# 📈 Dashboard Ejecutivo de Sell-Out y Rendimiento Comercial (Looker Studio)

## 🎯 Descripción del Proyecto
Tablero de control interactivo desarrollado para conectar bases de datos operativas y ofrecer visibilidad gerencial en tiempo real sobre el rendimiento comercial, rotación de inventarios y volumen de ventas por sucursal.

---

## 🛠️ Herramientas y Fuentes de Datos
* **Herramienta de BI:** Looker Studio.
* **Fuentes de Datos:** Google Sheets / Bases de datos estructuradas con registros de transacciones.
* **Métricas Principales (KPIs):** Ingresos totales en MXN, unidades vendidas, ticket promedio y análisis de rotación por canal.

## 💡 El Reto y la Solución
* **El Problema:** Los reportes de ventas dependían de procesos manuales en hojas de cálculo dispersas, lo que retrasaba la toma de decisiones para el resurtido.
* **La Solución:** Centralización de las fuentes de datos y diseño de un dashboard dinámico con filtros por fecha, región y categoría de producto, reduciendo el tiempo de generación de reportes gerenciales a cero (actualización en tiempo real).
