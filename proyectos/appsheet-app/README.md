# 📱 Aplicación Móvil Operativa para Gestión de Comercio y Cobros (AppSheet)

## 🎯 Descripción del Proyecto
Aplicación móvil y web desarrollada a la medida para optimizar el registro, control de padrones y seguimiento de pagos en vía pública, integrando bases de datos centralizadas y geolocalización.

---

## 🛠️ Stack Tecnológico
* **Desarrollo No-Code / Low-Code:** AppSheet.
* **Base de Datos y Respaldo:** Google Sheets / AppSheet Database.
* **Funcionalidades Clave:** Formularios en campo, control de roles/usuarios, geolocalización de puntos de cobro y trazabilidad de pagos.

## 💡 El Problema y la Solución
* **El Reto:** Descentralización en los registros operativos y dificultad para auditar cobros y movimientos en campo de forma inmediata.
* **La Solución:** Creación de una app intuitiva para que los operadores actualicen la base de datos en tiempo real desde sus dispositivos móviles, eliminando errores de captura manual y asegurando la transparencia en la recaudación.
